
# Explore Ofok (إكسبلور أفق)

**Tagline:**
Unlocking Earth's Hidden Treasures & Cultural Horizons with AI-Driven Geospatial Intelligence.

## About The Project
Explore Ofok is a smart exploration and tourism intelligence platform. It merges satellite geospatial analysis with Gemini API's multimodal intelligence to assess land capabilities (water/minerals) while delivering interactive cultural, historical, and educational insights for key destinations.

## Tech Stack
* **Backend:** Python, FastAPI, Uvicorn
* **AI Engine:** Google Gemini API (gemini-2.5-flash)
* **Frontend:** HTML5, Bootstrap 5, JavaScript
